# Predictive Forensic System

A web-based forensic analysis application designed to analyze crime data and identify potential patterns in serial criminal activities.

## 📌 Project Overview

The Predictive Forensic System helps analyze historical crime data and detect similar crime patterns based on factors such as location, timing, and related criminal activities.

The system provides a web-based interface for managing crime and suspect information, viewing analytical results, and identifying patterns through visualizations.

## 🚀 Features

* Crime data management
* Suspect data management
* User registration and login
* Crime pattern analysis
* Data visualization
* Crime trend analysis
* Timeline-based analysis
* Heatmap visualization
* Pie charts and bar charts
* Cluster analysis
* Dashboard for analytical insights
